# Sistema de venta de lotes
## Objetivo
Gestionar lotes y ventas mediante una arquitectura modular en Python 3.
## Integrantes
- Ángel Daniel Tapia Fernández
- [Integrante 2]
- [Integrante 3]
## Requisitos
- Python 3.10 o superior
- No requiere librerías externas
## Estructura
- main.py: menú y coordinación
- lotes.py: registro, búsqueda y disponibilidad
- ventas.py: registro y resumen de ventas
- validaciones.py: reglas de entrada
- calculos.py: total, cuota inicial y saldo
## Ejecución
1. Clonar o descargar el repositorio.
2. Abrir una terminal en la carpeta del proyecto.
3. Ejecutar: python main.py
## Pruebas
Se probaron registros correctos, cálculos, campos vacíos, valores no positivos,
códigos duplicados, lotes inexistentes y ventas repetidas.
